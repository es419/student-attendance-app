# נוכחות+

אפליקציית PWA סטטית למעקב נוכחות, שעות ושכר משוער.

## מבנה

- `index.html` — מבנה המסך בלבד.
- `styles.css` — כל העיצוב.
- `calc.js` — חישובי שעות ושכר (לוגיקה טהורה, בלי DOM ובלי רשת), עם בדיקות ב-`tests/`.
- `app.js` — Supabase, נוכחות, מסכים, ייצוא והגדרות.
- `vendor/` — ספריות צד שלישי מקומיות (Supabase ו-XLSX), בלי תלות ב-CDN.
- `sw.js` — cache, offline shell והתראות push.
- `manifest.json` — הגדרות PWA.

## בדיקות

```powershell
npm test
```

הבדיקות מכסות את חישוב השעות והשכר (רגילות, 125%, 150%, תקרה, הפסקות, מחלה, משמרת לילה, משמרת שנשכחה).
הן רצות גם אוטומטית ב-GitHub Actions בכל push.

## התנהגות משמרות

- משמרת שחוצה חצות (למשל 22:00–06:00) נשמרת ומחושבת נכון.
- משמרת פתוחה מעל 16 שעות נחשבת "נשכחה": האפליקציה (והבוט) לא מנחשים שעת יציאה, אלא מבקשים להזין אותה או לבטל.
- שעת הכניסה, ההפסקה והיציאה נקבעת ברגע הלחיצה, לא אחרי סיום הבקשה לרשת.
- כל עריכה קוראת קודם את הנתונים העדכניים מהשרת, כדי לא לדרוס שינוי מטלגרם או ממכשיר אחר.
- מחיקת יום ניתנת לביטול למשך כמה שניות.

## הרצה מקומית

```powershell
py -m http.server 8000
```

ואז לפתוח `http://localhost:8000`.

## טעינה

יש שכבת loading חוסמת אחת בלבד:

- אם קיים snapshot מקומי, המסך מוצג מיד והסנכרון מול Supabase מתבצע ברקע.
- אם אין snapshot, הלוגו נשאר רק עד שהבקשה הראשונית ל-Supabase מסתיימת.
- אין timeout מלאכותי ואין spinner נוסף בתוך המסך.

## Telegram companion

הפרויקט כולל בוט Telegram שמתחבר לאותו חשבון ואותם נתוני נוכחות.

הבוט תומך בכניסה, יציאה, יציאה/חזרה מהפסקה, סטטוס נוכחי, סיכום היום ודוח החודש. החיבור לחשבון נעשה באמצעות קוד חד-פעמי מהגדרות האפליקציה.

### התקנה ב-Supabase

1. הרץ את המיגרציה שב-`supabase/migrations/20260918_add_telegram_companion.sql`.
2. הגדר Secrets לפונקציה: `TELEGRAM_BOT_TOKEN` ו-`TELEGRAM_WEBHOOK_SECRET`.
3. פרוס את `supabase/functions/attendance-telegram` ללא JWT verification.
4. הגדר את webhook של Telegram לכתובת הפונקציה עם אותו `secret_token`.

לא שומרים Bot Token בקוד או ב-Git.

## אבטחה

- האפליקציה מתחברת עם המפתח הציבורי של Supabase, ולכן **ה-RLS הוא ההגנה היחידה על הנתונים**.
  ב-`supabase/migrations/20260929_core_tables_rls.sql` יש הגדרות ל-`kv_store`, `push_subscriptions` ו-`break_reminders`.
  בדוק בדשבורד אם הן כבר מופעלות, ואם לא — הרץ את הקובץ.
- ה-webhook של Telegram נסגר כברירת מחדל: בלי `TELEGRAM_WEBHOOK_SECRET` הפונקציה מסרבת לכל בקשה.
- ביציאה מהחשבון נמחק הסנאפשוט המקומי של נתוני השכר.
